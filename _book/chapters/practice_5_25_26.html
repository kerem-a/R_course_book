3. וקטורים!

נתעכב רגע על הפקודה c() שזו אחת הפקודות הכי שימושיות ב-R שבעזרתה אפשר ליצור את האובייקט הבסיסי ב-R שנקרא וקטור.

  • נתנסה ביצירה של עוד וקטורים בעזרת פקודת c() וניתן להם שמות:

    • וקטור שיקרא names שנשים בתוכו כמה שמות

    • וקטור שנקרא important_numbers עם כמה מספרים

    • ניצור וקטור שנקרא age_labels עם אותם יחידות של קטגוריות גיל ממקודם. ונחליף את האובייקט שיצרנו בקוד ליצירת age_group_f

  • נחשב ממוצע של הוקטור important_numbers

    👈 כשאנחנו קוראים למשתנה מסויים מתוך ה-DF שלנו בעזרת הסימן $. למעשה R מתייחס אליו כוקטור. למשל, כשבדקנו קודם את האורך של העמודה tool ב-DF שלנו בעזרת פקודת length אנחנו בעצם בדקנו את האורך של הוקטור שנקרא val_study_macro$tool 🤯

3. חזרה לגרף נקודות

  • ניצור גרף נקודות שמשווה בין האנרגיה לחלבון

  • נוסיף אלמנט של צבע על בסיס סוג הכלי ששימש להערכה תזונתית

  • נוסיף theme_classic כותרת: Protein vs energy וגם קו מגמה עם geom_smooth

  • נשנה גם את הכותרת מעל ה-legend של הגרף שלנו (ה-color) ל-Assessment tool

  • נשנה את הצבעים של הקטגוריות בעזרת הפקודה scale_color_manual נגדיר לה ידנית צבעים. הפעם לא בעזרת כתיבה של השם של הצבע אלא בעזרת קוד שנקרא hex - נחפש בגוגל color picker נבחר שני צבעים ונעתיק את ה-hex שלהם

  • נתיידד עם הפונקציה theme. נוריד בעזרתה את הכותרת של ה-legend ונעביר אותה למעל הגרף וגם נשנה את הצבע של הכותרת.

  • נוסיף facet_wrap עבור age_group - מבינים מה הבעיה?

  • נשנה את הפיצול של facet_wrap ל-age_group_f נוסיף nrow=3 על מנת להציג את הגרף בשלוש שורות במקום בטורים.

  • נקרא לגרף החדש protein_vs_energy_p2

4. גרף Boxplot

  • ניצור גרף קופסה עבור צריכת סיבים total_dietary_fiber נתנסה תחילה בלהגדיר את הסיבים בציר x ואז בציר y
  • נוסיף הגדרה שהצבע (fill) יוגדר בהתאם ל-age_group_f
  • נוסיף גם פקודה שמשנה את הצבעים לפי סט צבעים מוגדר מראש בעזרת scale_fill_brewer - Set2 הכי יפה!
  • נוסיף geom_jitter נשנה את ההגדרות לפי מה שמוצע בקוד (אין שום סיבה לנסות לזכור את הפורמט של הקוד הזה [זה נכון להרבה מהדברים שמוצגים בשיעור הזה], רק להבין מה אומרת כל הגדרה כדי לשחק איתה במידת הצורך).
  • נוסיף כותרת לגרף ולציר y.
  • בעזרת theme נסיר את axis.title.x, axis.text.x ו-legend.title
  • נקרא לגרף המפואר שלנו בשם fiber_boxplot_p
Press to show R code 


# simple boxplot
val_study_join_plot_ready %>% 
  ggplot(aes(x=total_dietary_fiber)) +
  geom_boxplot()

# simple boxplot y axis (more common)
val_study_join_plot_ready %>% 
  ggplot(aes(y=total_dietary_fiber)) +
  geom_boxplot()

#change colors
fiber_boxplot_p <- val_study_join_plot_ready %>%
  ggplot(aes(y=total_dietary_fiber, x=age_group_f, fill=age_group_f )) +
  geom_boxplot()+
  scale_fill_brewer(palette = "Set2")

#check the plot
fiber_boxplot_p

# add some extras
fiber_boxplot_p <- fiber_boxplot_p +
  geom_jitter(aes(color = age_group_f), # add points for each participant)
              position = position_jitter(width = 0.1), 
              size = 2, alpha = 0.6, show.legend = FALSE)+
  labs(title = "Total dietary fiber by age group", # add title
       y = "Total dietary fiber (g)")+
  theme(  # remove axis titles and legend title
    axis.title.x = element_blank(),
    axis.text.x  = element_blank(),
    legend.title = element_blank()
  )
#check the plot
fiber_boxplot_p

5. פיצול להרבה גרפים בסיוע pivot_longer

  • ניצור וקטור בשם my_nuts עם שמות השדות protein, food_energy, total_dietary_fiber, iron

  • נבחר את השדות שבוקטור my_nuts וגם את age_group_f

  • נעשה pivot_longer על כל השדות למעט age_group_f

  • ניקח את הקוד שהכנו מקודם לגרף boxplot ונשנה אותו קלות כך שיתאים למבנה החדש. נוסיף facet_wrap עם scales = “free”

  • ננסה להחליף את ה-boxplot ב-היסטורגרמות. צריך להוריד הגדרה לציר y ולשנות את ההגדרה של ציר X וגם להוריד את ה- stat_compare_means וה-geom_jitter נקרא לאובייקט nut_hist_p

Press to show R code 
my_nuts<- c("protein", "food_energy", "total_dietary_fiber", "iron")
# create a long data frame for multiple boxplots
val_study_long <- val_study_join_plot_ready %>%
  select(all_of(my_nuts), age_group_f) %>%
  pivot_longer(cols = -age_group_f,
               names_to = "nutrient",
               values_to = "value")

# create boxplot with almost the same code 
nut_boxplot_p <- val_study_long %>%
  ggplot(aes(x = age_group_f, y = value,fill = age_group_f)) + # change the y axis to x axis
  geom_boxplot() +
  geom_jitter(aes(color = age_group_f), 
              position = position_jitter(width = 0.1), 
              size = 2, alpha = 0.6, show.legend = FALSE)+
  labs(title = "Nutrients by age group" # change the title from fiber to nutrients
  )+
  theme(
    axis.title = element_blank(),
    legend.title = element_blank()
  )+
  facet_wrap(~nutrient, scales = "free") # split the graph based on nutrient add scales = "free" 

# check the plot
nut_boxplot_p


# create histogram with almost the same code
nut_hist_p <- val_study_long %>%
  ggplot(aes(x = value,fill = age_group_f)) +
  geom_histogram() +
  labs(title = "Nutrients by age group"
  )+
  theme(
    axis.title = element_blank(),
    legend.title = element_blank()
  )+
  facet_wrap(~nutrient, scales = "free") 

# check the plot
nut_hist_p

6. שמירה וסידור כמה גרפים ביחד

  • נתנסה בשמירה של גרף ישירות בעזרת כפתור ה-export

  • נתנסה בשימוש בפקודת ggsave גם כ-jpg וגם כ-pdf

  • נתקין את חבילת cowplot שעוזרת לסדר גרפים אחד ליד השני

  • בעזרת plot_grid נסדר ארבעה גרפים, נגדיר ncol=2, nrow =2 כדי שאכן יסתדרו כמו שאנחנו רוצים

  • נשמור עם save_plot

  • התוצאה רחוקה מלהיות מושלמת. ניתן לשפר את זה קצת בעזרת שינוי של הפרופרורציות של הקובץ ששומרים

  • ניתן לשפר את התוצאה עוד, בעזרת משחקים עם הגדלי טקסטים והקטנה של legend. זה מחוץ ל-scope שלנו לשיעור זה🫠
